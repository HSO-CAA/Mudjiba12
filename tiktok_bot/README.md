# TikTok Bot — لايك + حفظ + تعليق تلقائي

يراقب مجموعة حسابات، وأول ما واحد منهم ينزل فيديو جديد، البرنامج يسوي **لايك + حفظ + تعليق** من حسابك،
وكل حساب إله تعليقاته الخاصة. كلشي يتم من واجهة وحدة تنفتح بنافذة Edge، والعربي بيها يطلع مضبوط.

## التنزيل

1. بالريبو روح لـ **Actions** ← **Build TikTok Bot (exe)** ← افتح آخر run ناجح.
2. نزل **TikTokBot-windows** من قسم Artifacts وفك الضغط.
3. دبل كلك على `TikTokBot.exe`.

> البرنامج يستخدم متصفح **Microsoft Edge** الموجود بالويندوز (أو Chrome)، فما تحتاج تنزل شي ثاني.
> إذا طلع تحذير "Windows protected your PC" دوس **More info** ← **Run anyway**.

## أكثر من حساب (كل نافذة بحساب)

- كل مرة تفتح البرنامج يسألك: تختار حساب موجود لو تسوي حساب جديد.
- تريد 3 حسابات بنفس الوقت؟ دوس **🪟 نافذة جديدة** (أو افتح الـ exe مرة ثانية)، واختار حساب ثاني بكل نافذة.
- كل حساب إله تسجيل دخول وحسابات مراقبة وتعليقات وسجل خاص بيه.
- الحساب المفتوح بنافذة ما ينفتح بنافذة ثانية بنفس الوقت، حتى ما يصير تضارب.

## الاستخدام

| الجزء | شنو يسوي |
|---|---|
| **الحسابات** (يمين) | اكتب اسم الحساب ودوس **إضافة**. تكدر تكتب أكثر من اسم بنفس الوقت وتفصل بينهم بمسافة |
| **تعليقات الحساب** | اختار حساب من القائمة واكتب تعليقاته، كل سطر تعليق. ما يتكرر نفس التعليق إلا بعد ما يستخدمها كلها |
| **تعليقات عامة** | تنستخدم للحسابات اللي ما كتبتلها تعليقات |
| **الإعدادات** | كل كم دقيقة يفحص، وأقصى عدد فيديوهات بالساعة، وتشغيل أو إطفاء اللايك والحفظ والتعليق |
| 🔑 **تسجيل الدخول** | أول مرة بس: ينفتح Edge عادي، تسجل دخول (أو بـ QR من تطبيق تيك توك)، ولما تشوف حسابك سكّر المتصفح. بالسجل يطلعلك إذا الجلسة انحفظت |
| 🧪 **تجربة على فيديو** | تلصق رابط فيديو وتشوف إذا اللايك والحفظ والتعليق تشتغل |
| ▶ **تشغيل المراقبة** | يبدي. أول دورة يسجل آخر فيديو لكل حساب (ما يعلق على القديم)، وبعدها يتفاعل ويه أي فيديو جديد |
| ■ **إيقاف** | يوقف المراقبة |

لما تسكر نافذة البرنامج، المراقبة توقف والبرنامج يطفي.

كل حساب إله فولدر بـ `accounts\<اسم الحساب>` جنب الـ exe، بيه الإعدادات (`config.json`) والسجل (`bot.log`)
والحالة (`state.json`، احذفه إذا تريد يبدي من جديد) وجلسة تسجيل الدخول (فولدر `profile`، لا تحذفه).
تحذف حساب كامل؟ سكّر نافذته واحذف فولدره.

## ملاحظات مهمة

- التفاعل التلقائي **مخالف لشروط استخدام تيك توك**، وممكن ينحظر حسابك أو تنقيد تعليقاته. خلي الأرقام هادية ولا تكثر حسابات.
- إذا طلعتلك كابتشا بالمتصفح، حلها بإيدك والبرنامج يكمل.
- إذا السجل كال "ما لكيت جلسة تسجيل دخول"، عيد تسجيل الدخول. إذا تيك توك طلعك من الحساب بعد فترة، نفس الشي.
- إذا تيك توك غير شكل الموقع وبطل يلكه الأزرار، المحددات موجودة بأول `bot.py` (`SELECTORS`).

## التشغيل بدون exe (للمطورين)

```bash
pip install -r requirements.txt
python app.py                        # الواجهة
python bot.py <حساب> login|run       # بدون واجهة
```
