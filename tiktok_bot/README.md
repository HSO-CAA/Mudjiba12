# TikTok Bot — لايك + حفظ + تعليق تلقائي

يراقب مجموعة حسابات، وأول ما واحد منهم ينزل فيديو جديد، البرنامج يسوي **لايك + حفظ + تعليق** من حسابك،
وكل حساب إله تعليقاته الخاصة.

## تنزيل البرنامج (exe)

1. بالريبو روح لـ **Actions** ← **Build TikTok Bot (exe)** ← **Run workflow** (أو يشتغل وحده عند أي تعديل).
2. بعد ما يخلص (تقريباً 3 دقايق) افتح الـ run ونزل **TikTokBot-windows** من قسم Artifacts.
3. فك الضغط بفولدر، راح تلكه بيه `TikTokBot.exe` و `config.json`.

> البرنامج يستخدم متصفح **Microsoft Edge** الموجود بالويندوز (أو Chrome)، فما تحتاج تنزل شي ثاني.

## الإعدادات — `config.json`

افتحه بالمفكرة (Notepad):

```json
{
  "check_interval_minutes": [4, 8],
  "max_actions_per_hour": 10,
  "default_comments": ["تحفة 🔥", "استمر يا بطل 👏"],
  "accounts": {
    "username1": ["تعليق خاص بهذا الحساب 🔥", "تعليق ثاني 👏"],
    "username2": ["كلش حلو ❤️"],
    "username3": []
  }
}
```

| الإعداد | الشرح |
|---|---|
| `accounts` | أسماء الحسابات (بدون @) وتعليقات كل حساب. البرنامج ما يكرر التعليق إلا بعد ما يستخدمها كلها. إذا القائمة فاضية `[]` ياخذ من `default_comments` |
| `check_interval_minutes` | كل كم دقيقة يفحص (رقم عشوائي بين القيمتين) |
| `max_actions_per_hour` | أقصى عدد فيديوهات يتفاعل وياها بالساعة |
| `do_like` / `do_save` / `do_comment` | `true` أو `false` لتشغيل/إطفاء كل خاصية |
| `headless` | `true` حتى يشتغل المتصفح مخفي (خليه `false` بالبداية) |

## التشغيل

دبل كلك على `TikTokBot.exe` وتطلعلك قائمة:

1. **تسجيل الدخول** — أول مرة بس: ينفتح المتصفح، سجل دخول لحسابك، ارجع للشاشة السودة ودوس Enter.
2. **تشغيل المراقبة** — خلي النافذة مفتوحة. أول دورة يسجل آخر فيديو لكل حساب (ما يعلق على القديم)، وبعدها أي فيديو جديد يتفاعل وياه.
3. **تجربة على فيديو واحد** — الصق رابط فيديو وشوف إذا اللايك والحفظ والتعليق تشتغل.
4. **فتح ملف الإعدادات**

السجل ينحفظ بـ `bot.log`، والحالة بـ `state.json` (احذفه إذا تريد يبدي من جديد).

## ملاحظات مهمة

- التفاعل التلقائي **مخالف لشروط استخدام تيك توك**، وممكن ينحظر حسابك أو تنقيد تعليقاته. خلي الأرقام هادية ولا تكثر حسابات.
- إذا طلعتلك كابتشا بالمتصفح، حلها بإيدك والبرنامج يكمل.
- إذا تيك توك غير شكل الموقع وبطل يلكه الأزرار، المحددات موجودة بأول `bot.py` (`SELECTORS`).

## التشغيل بدون exe (للمطورين)

```bash
pip install -r requirements.txt
python bot.py login
python bot.py run
```
