# TikTok Bot — لايك + حفظ + تعليق تلقائي

يراقب مجموعة حسابات، وأول ما واحد منهم ينزل فيديو جديد، البرنامج يسوي **لايك + حفظ + تعليق** من حسابك،
وكل حساب إله تعليقاته الخاصة. كلشي يتم من واجهة وحدة.

## التنزيل

1. بالريبو روح لـ **Actions** ← **Build TikTok Bot (exe)** ← افتح آخر run ناجح.
2. نزل **TikTokBot-windows** من قسم Artifacts وفك الضغط.
3. دبل كلك على `TikTokBot.exe`.

> البرنامج يستخدم متصفح **Microsoft Edge** الموجود بالويندوز (أو Chrome)، فما تحتاج تنزل شي ثاني.
> إذا طلع تحذير "Windows protected your PC" دوس **More info** ← **Run anyway**.

## الاستخدام

| الجزء | شنو يسوي |
|---|---|
| **الحسابات** (يمين) | دوس ➕ وأكتب اسم الحساب. تكدر تكتب أكثر من اسم بنفس الوقت وتفصل بينهم بمسافة |
| **تعليقات الحساب** | اختار حساب من القائمة واكتب تعليقاته، كل سطر تعليق. ما يتكرر نفس التعليق إلا بعد ما يستخدمها كلها |
| **تعليقات عامة** | تنستخدم للحسابات اللي ما كتبتلها تعليقات |
| **الإعدادات** | كل كم دقيقة يفحص، وأقصى عدد فيديوهات بالساعة، وتشغيل أو إطفاء اللايك والحفظ والتعليق |
| 🔑 **تسجيل الدخول** | أول مرة بس: ينفتح المتصفح، تسجل دخول، وتسكر المتصفح |
| 🧪 **تجربة على فيديو** | تلصق رابط فيديو وتشوف إذا اللايك والحفظ والتعليق تشتغل |
| ▶ **تشغيل المراقبة** | يبدي. أول دورة يسجل آخر فيديو لكل حساب (ما يعلق على القديم)، وبعدها يتفاعل ويه أي فيديو جديد |
| ■ **إيقاف** | يوقف المراقبة |

الإعدادات تنحفظ تلقائياً بـ `config.json` جنب الـ exe، والسجل بـ `bot.log`، والحالة بـ `state.json`
(احذفه إذا تريد يبدي من جديد). جلسة تسجيل الدخول تنحفظ بفولدر `profile`، فلا تحذفه.

## ملاحظات مهمة

- التفاعل التلقائي **مخالف لشروط استخدام تيك توك**، وممكن ينحظر حسابك أو تنقيد تعليقاته. خلي الأرقام هادية ولا تكثر حسابات.
- إذا طلعتلك كابتشا بالمتصفح، حلها بإيدك والبرنامج يكمل.
- إذا تيك توك غير شكل الموقع وبطل يلكه الأزرار، المحددات موجودة بأول `bot.py` (`SELECTORS`).

## التشغيل بدون exe (للمطورين)

```bash
pip install -r requirements.txt
python app.py              # الواجهة
python bot.py login|run    # بدون واجهة
```
